# SYSTEM 33%

Профессиональный трекер роста MMR в Dota 2 по системе 33% (ориентир идеального WR — 66%).

## Локальный запуск

Откройте `index.html` через локальный сервер (модули ES):

```bash
python -m http.server 8080
```

Затем http://127.0.0.1:8080

## Безопасность (прототип)

- Пароли не хранятся в открытом виде: PBKDF2-SHA-256, 120000 итераций + уникальная соль
- Сессия в `sessionStorage` с токеном и TTL 12 часов
- XSS: экранирование ника при выводе
- Данные пока в `localStorage` браузера (для теста). Для продакшена нужен backend.

## Формулы

- План MMR: линейно `(цель − старт) / 12` на цикл
- Max MMR при 66% WR: `игр × (2×0.66 − 1) × Δ`, где Δ = 25 MMR
- Текущий WR = победы / сыгранные
- Возможный WR = (победы + поражения с шансом) / сыгранные
